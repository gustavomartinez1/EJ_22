# EJ_22 — Pantalla principal con imagen y texto en Jetpack Compose

**Asignatura:** Desarrollo de Aplicaciones para Dispositivos Móviles — ITIC
**Alumno:** Gustavo Martínez Montes

App Android en Kotlin + Jetpack Compose que muestra una pantalla de presentación:

- `Surface` con fondo personalizado y `Box` centrado.
- `Column` con una ilustración (`Image` con esquinas redondeadas y `ContentScale.Fit`).
- Dos textos con distintas fuentes, pesos, colores y alineaciones.
- Textos y descripción de imagen desde `strings.xml`.

## Ejecutar
Abrir la carpeta en Android Studio y correr el módulo `app` en un emulador o dispositivo (minSdk 24).
